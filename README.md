# Hi there!

Welcome to the repo for my personal portfolio site, built with Next.js and styled with Tailwind CSS.

It uses a zoom-scroll navigation — you scroll to zoom through layers, each one a different section of the portfolio. No pages, no routes, just one smooth dive.

## What's inside

- **Hero** — name, title, socials
- **PomodoroPet** — focus timer with a virtual pet
- **wordmirror** — vocabulary app with AI-powered sentences
- **Mumbai-local-bot** — NLP chatbot for Mumbai local trains
- **Overview** — everything at a glance, with a way to say hello

## Run it locally

```bash
npm install
npm run dev
```

Then open [localhost:3000](http://localhost:3000).
